A mens clothing storefront — React 19 and TypeScript on the front, Flask behind it.

Flask application factory with separate admin, shop and API blueprints, SQLAlchemy models for products, orders and order items, Flask-Login on the admin side and CSRF on the form routes, exempted for the JSON API the React client talks to. Order items keep the product name and unit price as they were at purchase time, so old orders stay correct when prices move.
